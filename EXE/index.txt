/EXE

This folder contains all executables and last delivery's testing files for the Hidato game.

Subdirectories:
- hidato.jar - Executable for the Hidato game app.
	       Can be executed with: java -jar hidato.jar
		   It will only work in Linux based systems with JDK installed.
		   If you encounter problems executing with this file,
		   go to /FONTS directory and execute ./gradlew build && ./gradlew run

- /test_sets - Contains data files for testing
