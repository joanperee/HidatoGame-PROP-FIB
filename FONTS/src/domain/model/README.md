FONTS/src/domain/model

This directory contains the domain layer classes.

Files:
- Cell.java - Implementation for the class representing a cell of an Hidato.

- GameSession.java - Implementation for the class representing a match or game session.

- Hidato.java - Implementation for the class representing the an hidato.

- Hexagon.java - Implementation of an hidato with hexagon form cells.

- Triangle.java - Implementation of an hidato with triangle form cells.

- Square.java - Implementation of an hidato with square form cells.

- User.java - Implementation for the class representing a user on the app.
